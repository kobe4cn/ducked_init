# MongoDB 数据源经 DuckDB 社区扩展 mongo 读取，权限另用驱动查询

MongoDB 与其他数据源一样，在独立的内存 DuckDB 里只读挂载（ADR-0009），采集和同步因此可以共用同一套 SQL。读取用的是 DuckDB 社区扩展 `mongo`（stephaniewang526/duckdb-mongo）：`ATTACH 'dbname=<库>' AS src (TYPE mongo, SECRET …, READ_ONLY)` 把库映射成 schema，每个集合映射成一张表。挂载后关闭 `mongo_enable_direct_scan`，`mongo_scan` 只能读已挂载的这个库，然后锁定配置。

这个扩展不能向 MongoDB 发命令，所以账号权限另用官方 Node 驱动执行 `connectionStatus`（带 showPrivileges）来查询。这个命令只读，任何已认证的账号都能查自己的权限。用途有两个：
- 可写即拒（ADR-0009）：列出账号在任何库、任何集合上的写类操作。写类操作包括写入、改结构，以及建用户与授权（能给自己授权等同可写）。
- 读权限：账号能读哪些集合（`find`）、能否列出集合（`listCollections`）。部分集合读不了时照常登记，采集跳过这些集合；一个都读不了时拒绝登记，并给出授权语句。

另外，驱动会先以不带账号的连接尝试列库。能列出，说明服务没有开启访问控制，任何连接都能写入，这种数据源一律拒绝。连接问题（如密码错误）也在这一步由驱动报出，因为扩展列集合失败时只会返回空清单。

## 表结构与水位线

- 列由扩展对每个集合抽样前 100 个文档推断：
  - 嵌套文档展开成以下划线连接的列（如 `address_city`），同时保留整个子文档的 JSON 文本。
  - 数组映射成 LIST。
  - Decimal128 转成 DOUBLE，会损失精度。
  - ObjectId 转成 24 位十六进制文本。
- 只出现在样本之外的字段不会成为列。以后需要时，可以用集合里的 `__schema` 文档或显式列定义补上。
- 更新时间候选的识别与其他数据源相同（按命名，时间类型，样本中没有空值）。
- 样本里 `_id` 全是 ObjectId 时，它作为自增主键类的水位线候选：ObjectId 的前 4 字节是创建时间，十六进制文本的字典序与 ObjectId 的顺序一致。
- 全量比对（ADR-0010）以 `_id` 作键。每个集合都有 `_id`，而且唯一。

## 已接受的取舍

- 依赖一个社区扩展：维护与 DuckDB 版本适配都取决于作者，出了问题需要自行修补或替换。
- 这个扩展不遵守 `enable_external_access = false`。锁定配置之后，会话里仍然可以再 `ATTACH` 一个 MongoDB（PostgreSQL 扩展会拒绝）。会话里只执行平台写死的只读查询（ADR-0009 第三层），成员与模型都给不出 SQL，所以风险可控；但“锁定配置后不能挂载其他库”这一层对 MongoDB 不成立。
- 扩展把连接参数拼成连接串，而连接串里的选项可以让驱动读取本机文件（如 `tlsCAFile`）。因此主机只接受主机名字符，库名与认证库不接受空格和 `/ \ . " $ * < > : | ? = &`，并且不开放自定义连接选项与 CA 证书。
- 驱动只把 ObjectId 的秒级时间放在前 4 字节，多个客户端各自生成的 ObjectId 在同一秒内并不严格递增。按 `_id` 作水位线，可能漏掉同一秒内晚到的文档；而且只能发现新增，发现不了修改。所以它只是候选，要由成员确认。

## Considered Options

- 用 Node 驱动把文档读成 JSON 再装进 DuckDB：不依赖社区扩展，但要自己实现结构推断、类型映射和分批拉取，大集合还得先落到本机临时文件。暂不采用。
- 变更流（change stream）：需要副本集，而且要保存 resume token。与 CDC 一起留到第二期（ADR-0010）。
