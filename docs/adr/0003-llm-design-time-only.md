# 大语言模型只在设计时产出声明式草稿，不参与运行时计算

平台要求计算结果可复现、不可出错，而大语言模型的输出不确定。决定：大语言模型只用于生成映射、指标定义、标签定义和数据质量断言的草稿，输出必须通过 JSON Schema 校验，由确定性编译器编译为 SQL，在样本上空跑并通过断言后，由成员审阅差异并发布。运行时只执行已发布的版本，不调用大语言模型；数据源结构指纹命中已发布映射时直接复用。

## Considered Options

- 运行时由大语言模型按需生成 SQL（Text-to-SQL）：灵活，但同一问题可能得到不同结果且难以审计，否决。
- 大语言模型直接产出 SQL 供审阅：比 DSL 更自由，但审阅成本高、跨租户不可复用，否决。

## Consequences

- 需要设计并维护一套指标/标签 DSL 及其编译器，DSL 表达力决定了平台能力边界。
- 标准模型之外的临时探索分析仍需要一个受控的自由 SQL 通道（见后续权限设计）。
